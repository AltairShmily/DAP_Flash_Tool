## 3. 修复计划（按优先级排序）

### Phase 1：后端运行时阻断修复

#### 1.1 补充 file_service.py 的 grpc import

- **文件**：`backend/services/file_service.py`
- **改动**：在第 8 行（`import os` 之后）添加 `import grpc`
- **影响**：修复 `PreviewFirmware` 和 `GetFileInfo` 两个 RPC 的 `context.abort()` 调用
- **验证**：`python -c "from services.file_service import FileServiceMixin"` 无 NameError

#### 1.2 Pack 安装职责解耦

- **文件**：`backend/services/pack_service.py`
- **改动**：
  - `InstallPack`（第68-76行）：移除对 `self._active_driver` 的依赖，改为调用 `self._pack_manager.install_pack(request.pack_path)`
  - `ListInstalledPacks`（第78-94行）：移除对 `self._drivers` 的遍历，改为调用 `self._pack_manager.list_installed_packs()`
- **前提**：需在 `pack/pack_manager.py` 中确认/补充 `install_pack()` 和 `list_installed_packs()` 方法
- **影响**：Pack 安装不再依赖设备连接状态

### Phase 2：前端功能修复

#### 2.1 Pack 下载链路修正

- **文件**：`flutter_app/lib/pages/pack_page.dart`、`proto/dap_flash.proto`、后端 pack_service.py
- **改动**：
  - 方案 A（推荐）：在 `PackInfo` proto 中增加 `download_url` 字段，仅在线搜索结果填充此字段；前端下载按钮仅在 `download_url` 非空时启用
  - 方案 B：前端增加 URL scheme 校验（`http://` / `https://`），本地路径禁用下载按钮
- **影响**：修复 Pack 下载必然失败的问题

#### 2.2 固件预览页接入 gRPC

- **文件**：`flutter_app/lib/pages/firmware_preview_page.dart`
- **改动**：
  - 引入 gRPC service 客户端
  - `_loadPreview()` 方法中调用 `PreviewFirmware` RPC
  - 展示返回的 hex_dump、total_size、file_format
  - 分页逻辑对接 offset/length 参数
- **影响**：固件预览从占位变为真实功能

### Phase 3：文档与质量修复

#### 3.1 设置页文案修正

- **文件**：`flutter_app/lib/pages/settings_page.dart`

#### 3.2 测试文件修正

#### 3.3 Flutter API 废弃迁移
